# 截图打码 Screenshot Mask

SillyTavern（酒馆）扩展。截图分享聊天之前，一键把 **user / char / NPC 的名字**打码。

- 打码方式有四种可选：**替换成代号**、**黑条遮盖**、**模糊**、**贴纸**（可以上传自己的小图片，也可以用 emoji）
- 自动识别当前的 user 名、char 名和群聊成员，不用手动填写
- NPC 名字和其他想隐藏的词写在词表里，支持别名和自定义代号
- 头像可选：不处理 / 模糊 / 盖贴纸
- **只修改页面显示**，不会改动聊天记录，也不影响发给 AI 的内容；关掉分享模式就会完全恢复
- 新生成的消息（包括流式输出）会自动打码

## 安装

酒馆 → 顶部「扩展」🧩 → 「安装扩展」→ 粘贴本仓库的 Git 地址 → 安装。

## 使用

1. 点输入框左边的魔杖菜单 🪄 →「分享模式：关」，切换成「开」
2. 截图
3. 再点一次就恢复

详细设置在「扩展」面板里的「截图打码」中。

### 词表写法

每行写一个（也可以用逗号分隔）：

| 写法 | 效果 |
| --- | --- |
| `李管家` | 自动编号：NPC1、NPC2… |
| `李管家=管家` | 自定义代号 |
| `李管家\|老李=管家` | 多种写法都换成同一个代号 |
| `Alice\|小爱=A` | 给 char 加昵称，或覆盖 char 的默认代号 |

- **角色专属词表**：只在当前角色或群聊中生效
- **全局词表**：所有聊天都生效

英文名会按完整单词匹配（`Ann` 不会把 `Anna`、`Banner` 也打码），中文名直接按文字匹配。
