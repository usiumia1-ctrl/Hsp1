# 预言家日报 · 酒馆状态栏美化

把 AI 每轮输出的 `<prophet_status>` 纯文本块，渲染成一份《预言家日报》头版：
报头徽记、双线报眉、四格信息条、黑底类别标签、巨号中文头条、双栏正文（首字下沉）、
会动的版画照片、可信度栏与魔法部圆印。**默认折叠**，点报头展开；可切晨刊 / 夜刊；窄屏自动改单栏。

## 文件清单

| 文件 | 用途 |
| --- | --- |
| `预言家日报-正则.json` | **推荐**：SillyTavern 正则，直接导入即可用（已内置单行版 HTML） |
| `预言家日报-替换模板-单行版.txt` | 手动配置时贴进「替换为」的内容（单行，防止被 Markdown 打断） |
| `预言家日报-替换模板.html` | 可读版源码，改配色 / 改文案看这个（改完需重新压成单行） |
| `预言家日报-正则-查找式.txt` | 查找正则表达式 |
| `预言家日报-输出格式指导.md` | 发给模型的提示词（世界书 / 预设 / 角色卡三选一） |
| `预言家日报-效果预览.html` | 浏览器直接打开看效果，含两条示例新闻（一份展开一份折叠） |
| `build.py` | 改完可读版后跑一次，自动重建预览页、单行版和正则 JSON |

## 安装（三步）

1. **装提示词**：把 `预言家日报-输出格式指导.md` 里「指导正文开始 / 结束」之间的内容，粘贴进
   世界书常驻条目（蓝灯）、预设的 Post-History Instructions、或角色卡描述末尾，三选一。
2. **装正则**：酒馆 → 扩展 → Regex → 导入正则 → 选 `预言家日报-正则.json`。
3. 随便回一句，模型给出 `<prophet_status>` 块后就会自动变成报纸。

### 手动配置（不想导入 JSON 时）

新建正则脚本，按下表填：

| 项 | 值 |
| --- | --- |
| 脚本名称 | 预言家日报 · 常驻新闻状态栏 |
| 查找正则 | `预言家日报-正则-查找式.txt` 全文（含首尾斜杠与 `gi`） |
| 替换为 | `预言家日报-替换模板-单行版.txt` 全文 |
| 作用于 | ✅ AI 输出 |
| 其他选项 | ✅ 仅格式显示（markdownOnly）、✅ 编辑时运行 |

> 「仅格式显示」很重要：勾上之后上下文里保留的仍是纯文本块，
> 不会把一大段 HTML 塞回提示词浪费 token，也不会让模型学着去仿写 HTML。

## 为什么替换文本必须是单行

酒馆在渲染前会走一遍 Markdown，**多行 HTML 的空行会被转成 `<br>`**，一旦插进 `<style>` 里，
整块 CSS 就废了（表现为：报纸变成一堆裸文字）。所以实际使用的是压缩过的单行版。

改样式的流程：改 `预言家日报-替换模板.html` → 跑一次 `python3 build.py` → 重新导入
`预言家日报-正则.json`（或把新的单行版贴回正则的「替换为」）。build.py 会顺带刷新效果预览页。

## 字段对照

```
<prophet_status>
[Date|$1 当前日期|$2 星期或副标]
[Time|$3 当前时间|$4 时段描述]
[Headline|$5 类别|$6 标题|$7 摘要|$8 来源|$9 可信度]
</prophet_status>
```

- `$1 $3` 同时出现在顶栏和头条署名行；`$8` 出现在顶栏、署名和右栏。
- 建议字数：类别 4–6 字，标题 10–30 字，摘要 80–200 字，来源 ≤16 字。
- 可信度固定五选一：已证实 / 官方口径 / 多方消息 / 未经证实 / 编辑部存疑。

## 交互与兼容

- **折叠**：默认收起，只显示一行「THE DAILY PROPHET + 头条标题 + 展开全文 ▼」，点报头展开。
  想改成默认展开，把模板里的 `<details class="dp-paper">` 写成 `<details class="dp-paper" open>`。
- **晨刊 / 夜刊**：右上角按钮切换。用的是 `checkbox + :has()`，**不含任何 `<script>`**，
  所以在禁用 JS、或对 script 做净化的酒馆版本里也能用。
- **窄屏**：用 `@container` + `@media` 双保险，手机端自动变单栏、隐藏装饰栏。
- 容错：字段前后多余空格、全角竖线 `｜`、`Date/date` 大小写、块内换行与否，都能匹配。

## 自定义

改 `预言家日报-替换模板.html` 顶部的两组变量即可换配色：

```css
.dp-root{                       /* 晨刊 */
  --dp-paper:#efe7d3;   /* 纸色  */
  --dp-ink:#15120c;     /* 墨色  */
  --dp-seal:#8d2417;    /* 印章  */
  --dp-grain:.34;       /* 颗粒感强度，0 为干净纸面 */
}
.dp-root:has(.dp-mode-input:checked){ /* 夜刊 */ }
```

其他常改的地方：

- 报名文案：`.dp-mast-cn` / `.dp-mast-en` / `.dp-mast-tag` 那三行。
- 顶栏第三格「首版 · 次版合刊 / 猫头鹰特急专送」是静态文案，可随便改。
- 页脚「魁地奇 8 / 保安司 10 …」为装饰性栏目条，可改成自己世界观的版面号。
- **版画插图**：右栏那张「会动的照片」是手写的内联 SVG（霍格沃茨城堡 + 送信猫头鹰 + 月亮），
  不走任何外链，离线、换设备、酒馆屏蔽外部图片都不会裂，也不涉及版权。
  - 不想要：删掉 `<figure class="dp-photo">…</figure>` 整段即可。
  - 不想让它动：删掉 `.dp-owl` 与 `.dp-wing` 里的 `animation` 两行（系统开了「减少动态效果」时本来就会自动停）。
  - 想换成自己的图：把 `<svg class="dp-photo-fig">…</svg>` 整段换成
    `<img class="dp-photo-fig" src="图片地址" alt="">`。
    **不建议外链哈利波特官方剧照或别人的同人图**——版权归华纳 / 原作者，而且外链图在部分酒馆前端
    会被拦截或加载失败。要用就用自己有权使用的图，并尽量转成 base64 内嵌
    （`src="data:image/png;base64,…"`），代价是正则会变得很长。
- 不想要左侧装饰性排字：删掉 `<div class="dp-filler">`，并把 `.dp-plate` 的
  `grid-template-columns` 改成 `1fr 172px`。

## 常见问题

- **报纸没出来，只看到纯文本块**：模型没按格式写（多半是竖线数量不对，或用了代码块包起来），
  或正则「作用于 AI 输出」没勾。把格式指导挪到更靠后的位置（如 Post-History）通常能压住。
- **只出现一部分、后面糊了**：摘要里出现了 `|` 或 `]`。格式指导里已禁止，可在提示词里再强调一次。
- **字体不对**：`@import` 的 Google Fonts 被墙或被净化。中文会自动回退到思源宋体 / 宋体，
  版式不受影响；介意的话可以把 `@import` 那行删掉。
- **一楼有两份报纸**：模型输出了两个 `<prophet_status>` 块。正则带 `g`，会各渲染一份，
  这是模型问题不是正则问题。
