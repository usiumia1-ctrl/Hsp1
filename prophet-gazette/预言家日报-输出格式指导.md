## 核心响应要求

每次完成小说正文后，必须在正文末尾另起一行，严格输出一份完整的「预言家日报新闻状态栏」。

正文必须正常书写，状态栏不得替代、压缩或打断正文。状态栏必须是正文结束后的最后一项内容。如果当前回复还需要输出其他固定模块，则将本状态栏放在正文之后、总结之前。

必须严格使用以下纯文本结构：

```
<prophet_status>
[Date|{{当前日期}}|{{星期或日期副标}}]
[Time|{{当前时间}}|{{时段描述}}]
[Headline|{{新闻类别}}|{{头条标题}}|{{新闻摘要}}|{{消息来源}}|{{可信度标签}}]
</prophet_status>
```

## 格式填充规则

### 1. 强制性

- 每次小说正文结束后都必须完整输出一次 `<prophet_status>` 结构。
- 不得省略 Date、Time 或 Headline 中的任何字段，共九个字段，缺一不可。
- 所有竖线分隔符必须保留，且必须使用半角竖线 `|`。
- 字段内部禁止使用 Markdown、HTML、代码块反引号、额外的方括号或竖线。
- 状态栏内只允许出现一条新闻，不得生成第二条新闻。
- 不得把 `<prophet_status>` 包进代码块，不得在 `</prophet_status>` 之后补充任何解释性文字。
- 字段内部不要换行；摘要即使较长也写成连续一段。

### 2. 日期规则

- 「当前日期」必须与小说正文所处时间完全一致。
- 格式优先使用「1971年12月1日」。
- 如果正文只能确认月份或季节，允许使用「1971年12月上旬」或「1971年冬季」，不得擅自虚构精确日期。
- 「星期或日期副标」可填写「星期三」「十二月号外」「冬季学期」等符合当前场景的信息。
- 不得把后续时间线中的日期提前使用。

### 3. 时间规则

- 「当前时间」应使用自然中文，如「下午四时二十分」「午夜将近」「清晨六时许」。
- 如果正文没有提供精确分钟，只写合理的模糊时间，不得无依据精确到分钟。
- 「时段描述」应为简短氛围词，如「黄昏将至」「晚宴之前」「宵禁以后」「冬日午后」。
- 时间必须与正文中的光照、课程、用餐、宵禁和人物行程保持一致。

### 4. 头条新闻选材

- 每次只能选择一条最适合作为本轮状态栏内容的新闻。
- 新闻不必与主角直接相关，可以来自霍格沃茨、英国魔法界或合理范围内的国际魔法界。
- 新闻允许是小事：魁地奇结果、恶作剧、神奇动物走失、名人绯闻、商品广告争议、学校传言。
- 新闻允许是当年的社会大事：魔法部政策、纯血政治、歧视事件、失踪案、国际变革或安全局势。
- 新闻允许成为后续剧情伏笔，但伏笔必须表现为当前年代已经出现的细节、传闻、异常或公开事件，不能直接泄露未来真相。
- 新闻允许刊登某些人物的自吹自擂、刻意宣传或政治表演，不要求报纸本身始终客观。
- 新闻允许不可靠、夸张、偏颇或带有编辑立场，但不得把作者层面的未来知识包装成报社已知事实。
- 霍格沃茨内部的小事件应使用「校内快讯」「学生来稿」「匿名爆料」等类别，不必假设全国性报纸真的把每场学生游戏刊登为全国头版。

### 5. 新闻类别

从以下类型中选择一个，或生成同等简短且符合语境的类别：

「魔法部政讯」「社会观察」「校内快讯」「魁地奇专栏」「巫师娱乐」「商业奇闻」「国际版」「匿名爆料」「紧急号外」「编辑部传闻」。

类别应控制在十个汉字以内，建议四至六字，因为它会被排成头条上方的黑底标签。

### 6. 头条标题

- 标题需具有《预言家日报》式的醒目感，可以严肃、夸张、煽动、故作权威或带有双关。
- 建议长度为十至三十个汉字；超过三十字会挤压版面。
- 标题必须只描述当前合理可知的信息。
- 不得为了戏剧性直接宣布尚未发生的原著事件。
- 可使用问号或感叹号，但避免连续堆叠标点。

### 7. 新闻摘要

- 使用二至四句连贯文字，建议八十至二百字。
- 摘要应交代事件、相关人物或机构、已知影响，以及必要的不确定信息。
- 新闻可以带有报纸腔调和编辑偏见，但叙述必须符合当年英国魔法社会的知识、技术和政治环境。
- 如果新闻涉及主角或在校学生，只能报道可能被旁观者、教授、校报或投稿人获知的内容，不得泄露人物私下谈话、隐藏计划、秘密地点或内心活动。
- 不得擅自宣称任何角色接受了采访，除非正文明确发生过采访。
- 不得把尚未公开的狼人身份、非法阿尼马格斯计划、魂器知识或其他秘密写成报纸已确认事实。
- 新闻可以对事实产生误解，这种误解应符合消息来源能够观察到的表象。

### 8. 消息来源

- 使用简短来源，如「预言家日报驻霍格沃茨通讯员」「魔法部新闻办公室」「匿名猫头鹰来函」「《女巫周刊》联合供稿」「对角巷商户协会」。
- 来源必须具有合理的信息渠道。
- 来源不能是「作者」「系统」「原著」「未来记忆」等叙事外来源。
- 建议不超过十六个汉字。

### 9. 可信度标签

必须从下列五项中选择一项，且只写标签本身，不加解释：

「已证实」「官方口径」「多方消息」「未经证实」「编辑部存疑」

- 标签反映新闻本身的可靠程度，而不是作者对未来剧情的判断。
- 政府发布的信息可以标注「官方口径」，但这不代表内容绝对真实。
- 谣言、娱乐爆料或来源单一的消息应标注「未经证实」或「编辑部存疑」。

### 10. 时间线与知识边界

- 严格遵循当前剧情日期和已经发生的事件。
- 原著未来事件不是必然剧本，不得将尚未发生的未来结果作为事实预告。
- 如果主角改变了关键因果，新闻必须根据变化后的现实自然演算。
- 所有报纸内容都必须基于当时能够被记者、公众、魔法部、学校人员或消息人士合理获知的信息。
- 可以制造伏笔，但伏笔必须保持不完整、可误读且符合当时证据。

### 11. 连续性

- 新闻应随时间推进而更新，不要机械重复上一轮标题。
- 同一事件仍在发展时，可以发布后续报道，但摘要必须体现新增信息。
- 如果本轮正文没有宏大事件，优先报道贴近场景的小新闻、校内轶闻、天气异常、消费潮流或社会传闻，不要强行制造战争级大事。

### 12. 示例（仅用于理解格式，不得固定复制）

```
<prophet_status>
[Date|1971年12月1日|星期三]
[Time|下午四时许|冬日黄昏]
[Headline|校内快讯|黑湖边雪球大战惊动半座城堡|霍格沃茨学生在黑湖边组织了一场规模可观的雪球对抗。目击者称，参赛者使用了诱敌、包抄和临时防御工事，数名高年级学生因此开始争论雪球是否应被列入正式校际运动。校方尚未就此发表意见。|匿名猫头鹰来函|多方消息]
</prophet_status>
```

## 字数建议（超出不会报错，只是版面会变松散）

- 类别 4–6 字；标题 10–30 字；摘要 80–200 字；来源 ≤16 字；可信度固定五选一。
